MISSION_ID: SCOPE_MODE_VISUAL_APPLY_V3

TITLE
Scope mode changes do not affect visuals — restore end-to-end mode propagation and render branching

SYMPTOM
- VST3 no longer crashes (good)
- Switching Scope Channel Mode (Stereo <-> Mid-Side) has no visual effect
Likely: mode value is not reaching StereoScopeView render branch OR branch uses wrong buffers/never re-renders.

GOAL
- Changing scopeChannelMode must reliably change what’s drawn:
  - Stereo: x=L, y=R (or your chosen axes)
  - Mid-Side: x=Mid, y=Side (or your chosen axes)
- Must repaint immediately and deterministically
- No crash, no allocations on audio thread

HARD RULES
- Minimal diffs
- Do NOT change parameter order
- Do NOT remove bounds checks that fixed crash
- Prefer render-only changes + correct wiring
- No allocations in paint()

FILES ALLOWED
- Source/ui/MainView.cpp (or wherever scopeChannelMode is consumed)
- Source/ui/scope/StereoScopeView.cpp
- Source/ui/scope/StereoScopeView.h
- Source/ui/layout/ControlRail.cpp (only if attachment mapping is wrong)
